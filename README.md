# 🚀 Clan Projects

Welcome to the clan's collaborative project space! This is where we brainstorm, build, and maintain real-world applications together.

---

## 🎯 Purpose

- Work together on team-based tech projects

- Each project lives in its own folder or sub-repo
- Use Issues and Projects tab for tracking
- Follow clan-wide contribution rules from [`clan-hub`](https://github.com/CircuLearn/clan-hub)
